# The Office — Wrestling Manager v2.3

The original sumo prototype has been replaced with **The Office**, a standalone wrestling management game.

## Play

Open `index.html` (or the GitHub Pages site). The complete playable game is dependency-free; no server or build step is required.

## Systems

16-week regional season; contract negotiation; wrestler recruitment and coaching; live text match nights with ringside decisions; rival promotions; persistent title pyramid; export/import of career saves; viewport-sized management screens navigated with Previous/Next buttons.

## Existing saves

The game imports local v2, v2.1, and v2.2 careers on the same origin. Save files can be exported and imported manually when moving between origins.

## Archive

The original sumo game is preserved on the `archive/sumo-before-the-office-2026-11-11` branch.
