# The Office — Switch Edition (first playable preview)

Separate entry point: `/wrestler/switch/`. The regular entry point and UI are not changed. The same career and match engine scripts are loaded in the same order, without the desktop UI or its onboarding script. Only the career storage declaration is parameterised: Switch Edition saves use `the-office-switch-v22`, and the in-progress match uses `the-office-switch-match-v1`. No migration from regular saves. Shared read-only dialogue caches can be reused.

The first slice is a real career, not a mockup: suggested identity, scouting/signing, inbox decisions, training, booking and bargaining with promoters, choosing a match structure and discussing a signed backstage layout, stepping real match commentary, ringside calls, resolving mandatory match decisions, settling results, and advancing weeks. Optional pauses and speech are available. The existing Hub-compatible scan and voice bundle and input bridge are reused from Dungeon Quest. The vendor bundle includes upstream attribution and license. 

Not yet exposed: pre-match promos, post-bell angles, comprehensive records, Ringfax, full difficulty options and cross-origin Hub setting transport. Some standard match-night orchestration (including signed sheets and recap) is desktop-specific and is intentionally not presented as parity. This is a development preview, not a claim of full compliance with [Benny's Hub ACCESSIBILITY.md](https://github.com/NARBEHOUSE/Narbehouse.github.io/blob/main/bennyshub/ACCESSIBILITY.md). Browser testing, actual switch testing, and scan-effort review remain release gates. 

Review: verify both entry points still load, ordinary save is never touched by a Switch Edition career, start a career, sign and book a wrestler, play through a match (including mandatory decisions), reload during a match, settle once, advance a week, verify pause/exit and shared scanning preferences. Do not add full regression jobs solely for the new UI.

## Commentary voices
Gloria (play-by-play), Vic (colour), and Ravi (production) are assigned distinct installed English speech voices whenever at least three are available, with preferred British/Indian voices where available. On limited devices, rate and pitch distinguish speakers. The player's saved NARBE menu voice is not changed. Commentary is queued as individual speaker turns using shared voice tickets and the scanner's existing Wait for Speech setting; manual navigation or disabled speech can interrupt it. The vendored manager has one documented per-utterance voice override. No prerecorded or cloud voices are required.

## Booking negotiations
Switch Edition now exposes existing V2 bargaining: fee, protected loss, billing, stipulations, arguments, counteroffers, concrete trades, hardball and withdrawal. The game preserves proposed versus accepted versus signed terms and uses actual career meeting and trust costs. Long option sets are paged (three responses plus navigation); conversation history and promoter advice are available separately. Programme offers remain direct-sign only, matching the regular edition. No new engine or workflow changes.

## Backstage planning
The Switch Edition exposes the regular OfficeRoom engine: mandatory choice of one of the five structures, dramatic lead for editorial structures, game plan, finishing route, optional named objectives or called spots, wrestler objections and bargaining, final review, curtain advice and signed sheet execution. Three responses per page; the board is split into finish and objective submenus. Dialogue banks and structured planning feature versions match the desktop orchestration. The in-progress room is saved separately and resumed on continue; actual witnessed structure/plan outcomes are recorded in career history. Ringside companion roles and post-bell angles are now exposed. No changes to the regular interface or engine.

## Pre-match microphone segments
The Switch Edition uses the existing OfficeMic, OfficeSegments and OfficeSigning engines: all offered segment types, directed promo duels with authored/fuzzy dialogue, available mouthpieces, public contract signings and programme chapter choices. Three response choices per page plus navigation; speech reads the latest dialogue and audience/tension feedback, with transcript review and pause available. Progress is saved with the backstage room; completed promo results and compatible public vows enter the real match engine. No engine, desktop UI or CI changes. Actual browser/switch testing remains necessary.

## Ringside and after the bell
Choose an eligible stablemate and their actual ringside assignment using the existing availability, injury, bond and match-rule checks. The signed sheet carries the corner plan into the match. Match settlement creates a career-persisted result/scene record in the same atomic commit; compulsory autonomous incidents must be resolved, while routine results can leave without a segment. Existing post-bell angle, follow-up and microphone choices use the real consequences engine and character dialogue. Three choices per page, spoken transcript, pause and resume. No change to the regular edition or workflows.

## Stable management and development
Wrestler profiles expose condition, skills, loyalty, wages and ambitions. Development includes weekly focus/intensity, injury-aware forecasts, fixed blocks/camps, Dennis's limited sessions (rehearsal, move learning, microphone practice), actionable training advice, specialist coaches and completed-week reports. Private meetings use the shared management-meeting allowance, with reassurance, featured-match promises and bonuses; permanent wage increases and releases require cancel-first confirmation. All actions use existing career APIs. No changes to the regular interface or engine. Browser and physical switch testing remain outstanding.

### Commentary playback
Commentary speaks only the actual line, retaining role-specific voices; commentator names remain visual labels. A complete spoken batch owns the scanner until it finishes in both switch modes, independent of the menu wait-for-speech preference. Long utterances are split at word boundaries, use a separate completion deadline, and stop on speech-engine failure rather than cutting into the next speaker. The last batch can be replayed. Normal menu scan timing is unchanged.

## Guided management and live broadcast
Guided management is the default Switch Edition presentation; Full management remains available from the office or pause menu. Dennis brings unresolved inbox decisions, urgent training recommendations, eligible offers (least-fatigued eligible wrestler suggested), and match night to the player. Leaving an offer for now only marks it reviewed for this career week; the real offer remains on the desk. No automatic bookings, expenditure, changes to training or difficulty. The traditional match layout is offered as a starting point, with all other structures available. Guided matches have continuous spoken commentary in small batches, paused at mandatory engine decisions, final bell, or a bounded ringside break (up to 12 lines or 90 simulated seconds, checked at batch boundaries). Enter during the broadcast opens Pause without advancing to another commentary line. Text-only play and Full management retain manual stepping. The engine and regular UI are unchanged. First guided UX iteration; physical switch/browser playtesting and further planning/promo streamlining are outstanding.

### Guided planning and promos
Dennis previews the existing engine's style-based plan, default finishing route and pencil-marked running order together. One approval commits both plan and board; actual backstage situations still require the manager's responses. Final review can explicitly approve the layout and give a calm closing reminder in one action. Detailed planning is always available before committing. For non-mandatory microphone segments, choose a crowd-focused solo, rivalry-focused solo, or short pre-taped promo; the actual segment engine performs the disclosed sequence of choices and plays the resulting dialogue. The full interactive segment remains available, and compulsory contract signings are never replaced. The first match broadcast begins automatically after Ring the bell in guided TTS mode. No new engine rules.

## Show-night presentation and streamlined scenes
The switch-only interface now has a show-progress strip, real paired wrestler portraits, visible backstage mood/step indicators, promo reaction indicators, match clock/crowd/calls and stamina bars, and clearly differentiated dialogue and decision cards. All data derives from existing state; visual indicators duplicate spoken information rather than creating extra scan targets. Guided planning offers one running-order approval and can proceed directly to the microphone after explicit layout/safety approval; real wrestler objections and mandatory choices remain. Guided promos offer a direct face-to-face route alongside concise presets, with full segment controls available. Guided scene speech is allowed to complete before scanning. Existing Full management and regular game are preserved. Browser and physical switch review still required.

## Contextual ringside advice
Guided spoken matches no longer stop at arbitrary line/time intervals. Dennis offers direct, legal existing ringside calls when the wrestler goes off the layout, struggles with stamina, loses crowd interest, comes under pressure, finds an opening, or approaches a difficult finish. Let them wrestle is always available and costs nothing. Advice begins after 45 simulated seconds, is separated by at least 65 simulated seconds, is limited to four prompts per match, and each situation is offered once. Mandatory engine decisions and final bell remain unchanged; the selection-switch pause opens the Pause menu immediately. Pending advice is saved with the match. Full management and manual text-only playback are unchanged. No new engine effects or RNG draws.

## Career difficulty (Switch Edition only)
Choose Standard or Relaxed when starting a career, or change an active career through Management mode → Career difficulty. Existing saves are Standard unless explicitly switched. Relaxed applies ordinary weekly costs, season and backer evaluations first, then adds an itemised support payment if the bank is below £750, before the bankruptcy check. Previous support remains in the balance if switching back to Standard. The support is visible in weekly accounts/review and can affect future cash-based objectives; it does not change match outcomes, injuries, booking eligibility, spending requirements, or wrestler behaviour. The regular edition never receives this support. No automatic decisions or new workflows.

## First launch and Hub settings (S8A)
A standalone or cross-origin launch without an explicit saved scan mode starts with one-switch Auto Scan (two-second interval) and Wait for Speech on. Enter selects; Space is not required. Existing explicit scan and speech preferences remain intact. A same-origin Benny's Hub frame retains the Hub's defaults and uses the existing shared scan/voice storage and origin-checked settings messages, including live changes. A separately hosted game cannot read the Hub's storage; the current Hub transport does not support cross-origin settings transfer. Local Settings remain accessible and changes are saved on the game origin. Cross-origin inheritance requires a compatible Hub-side change or same-origin hosting; no untrusted cross-origin messages are accepted. Physical-switch and browser/audio verification remain outstanding.

## Pause and emergency communication (S8C)
Stationary screens without an existing Pause choice expose Pause / help, including the main menu. Settings has its existing Back route. Continue restores the captured decision screen without repeating its game action; pending dialogue loading is invalidated before pausing and retried on resume. A short Enter press and release during live commentary cancels the current speech ticket and opens Pause without simulating another line. Continue returns to ringside choices, including replay, rather than automatically restarting the broadcast. I Need Help is near the start of Pause and says “I need help, please!” twice, even with normal TTS off. A compatible same-origin Hub communication service is preferred; otherwise forced local browser speech is used. Auto Scan holds the selected Help choice until the message finishes (bounded at 12 seconds), then waits the full scan interval; manual navigation remains available. The game reports playback failure or unconfirmed completion and never claims that a helper has been notified remotely. Speaker output and physical switch testing remain outstanding, especially when the game is hosted on another origin.

## Appearance and responsive layout (S8G)
Settings → Appearance offers highlight colour and outline/full-cell style, text colour, background theme and interface size. Each setting cycles independently, including Use Hub / default to remove a local override. The Switch Edition reads validated appearance values from the Hub's existing same-origin `narbe-hub-settings` storage, and refreshes on storage events. Local overrides are stored separately; the Hub is never modified. Cross-origin hosting cannot inherit those values automatically. With no saved appearance settings, the established Office palette remains. Explicit text colours use compatible reading backgrounds, the scan marker has a thick perimeter, and larger UI sizes use a single-column reading layout with scalable choices. Narrow screens wrap rather than shrinking text or clipping controls. Real-browser geometry, contrast and physical-switch testing remain to be verified.
