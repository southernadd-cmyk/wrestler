# The Office — Switch Edition (first playable preview)

Separate entry point: `/wrestler/switch/`. The regular entry point and UI are not changed. The same career and match engine scripts are loaded in the same order, without the desktop UI or its onboarding script. Only the career storage declaration is parameterised: Switch Edition saves use `the-office-switch-v22`, and the in-progress match uses `the-office-switch-match-v1`. No migration from regular saves. Shared read-only dialogue caches can be reused.

The first slice is a real career, not a mockup: suggested identity, scouting/signing, inbox decisions, training, booking existing offered terms, choosing a game plan, stepping real match commentary, ringside calls, resolving mandatory match decisions, settling results, and advancing weeks. Optional pauses and speech are available. The existing Hub-compatible scan and voice bundle and input bridge are reused from Dungeon Quest. The vendor bundle includes upstream attribution and license. 

Not yet exposed: full bargaining, signed dramatic structures, backstage dialogue/promos, post-bell angles, comprehensive records, Ringfax, full difficulty options and cross-origin Hub setting transport. Some standard match-night orchestration (including signed sheets and recap) is desktop-specific and is intentionally not presented as parity. This is a development preview, not a claim of full compliance with [Benny's Hub ACCESSIBILITY.md](https://github.com/NARBEHOUSE/Narbehouse.github.io/blob/main/bennyshub/ACCESSIBILITY.md). Browser testing, actual switch testing, and scan-effort review remain release gates.
