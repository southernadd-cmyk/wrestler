## R3/R4 — shared semantic responses

Four style pools contain two lines per route: 80 lines total for the ten completed
G4 routes. The existing 12 tactical families and individual delivery influence
seeded choice without separate copies of text. The actual live academy identity
is snapshotted for new scenes, rather than inferred from appearance or the bank ID.
Existing owner-specific, specialist and reviewed responses retain precedence;
recorded evidence, mouthpieces and protected cases retain their existing guards.
The same existing semantic selectors validate the shared rows. Stable shared IDs
enter the existing recent history (so a line cannot repeat across academy speakers
while in that history). Old scenes without the new flag retain old behaviour.
No compiled per-rookie assets are regenerated. Coverage tests use all 120 named
identities; real intake fixtures verify both speaker sides. This is targeted
reachability, not yet an organic frequency or editorial audit (R5/R7).

## R5A — organic utilisation and delivery preference

New scenes prefer existing direct versus reflective lines based on actual delivery
and current irritation/composure. Exact claim and protection checks still apply;
recent/used IDs always override the preference. Older saves retain seed-only
selection. No new speech or generated bank assets in this tranche. The two missing
source phrase sets and their asset rebuild remain a separate R5B change.

## R5B1 — high-frequency closing fallback

R5A CI recorded 241 shared semantic responses from 100 academy identities, 562
rolling-history repeated texts, and 73 changed paired transcripts. Total repetition
did not decrease. The leading repeated line was “I will win. That is all.” (192
emissions, 65 owners); the next three recurring phrases were opponent replies to
hard-earned victory vows. Target these actual closing variants rather than expand
all 120 generated packs. Four styles × four existing vow variants × two sides ×
two alternatives adds 64 shared lines. Existing owner-specific approved lines
retain priority. Each player vow must pass the closing commitment guard; opponent
replies only express the exact variant's disagreement. Save opt-in, protection,
recent IDs and delivery preference stay intact. The organic audit now compares
R5A versus R5B1 and requires reduction of the top repeated closing, reporting
overall repetition without assuming it improves. The missing phrase keys remain
R5B2, which requires a deterministic bank/manifest/claim asset rebuild.

## R6 — manifest-free future recruit dialogue

The original shared phrase compiler now lives with promo identity and is consumed
by both the browser and offline asset builder. The offline path still takes the
canonical editorial slot table and register profiles; the existing full asset
check must reproduce all shipped revisions. A future academy ID with no manifest
entry gets a deterministic 32-slot bank at the start of a new full semantic
scene. Known live academy voice and ambition aliases map to covered phrase keys;

normalised delivery are saved alongside the payload and exact-text claim map.

during a resumed scene. This does not create new wrestlers or extend the finite
career intake. Tests use synthetic future IDs in real promo choice paths.
