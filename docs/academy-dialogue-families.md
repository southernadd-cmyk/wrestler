# Academy dialogue R1/R2 — shared family architecture

No additional per-rookie writing. The previous generator already compiles named
academy identities from shared phrase sets. Keep those sets, the existing twelve
fallback voice packs, stable bank IDs and the 80 established wrestlers' authored
banks. The academy entrant with a dedicated editorial bank keeps it too.

The family catalogue uses four existing wrestling styles, each with three
existing tactical identities. Delivery, motivation, vulnerability, trigger and
pressure response remain independent facets, not new random personality labels.
The catalogue is a build-time planning tool; it does not change the live selector.

Run `node scripts/rookie-dialogue-families.cjs` for counts, or add `--json` for
the full ID mapping and exact slot/condition/claim-aware duplicate inventory.
The inventory preserves provenance and never authorizes transplanting lines
that depend on another person's traits or history. Existing generated output is
unchanged; only the duplicated pack compiler has been consolidated. Missing
phrase keys are reported explicitly rather than counted as covered by defaults.
