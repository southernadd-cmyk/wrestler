# MP6B — live private dialogue

MP6A CI covered 80 identities, seven delivery families, 10 owners
with 14 safe bank fragments, 79 real huddles and 316 composed lines
(81 bank reuses; 72 impact, six effort and one risk subjects).
This is narrow actual bank coverage, NOT full roster bank utilization.

New structured rooms use the existing lazy promo bank loader for the
two participants. Runtime rookies remain locally generated. A
meeting-specific token guards stale load completion and duplicate
requests; autosave contains no pending promise or full bank payload.
Missing/offline banks use shared identity composition. Existing rooms
and traditional match planning keep their previous policy.

Capture compact identities at room creation. Freeze request, response
and both revise-resolution lines at huddle opening, with unique used
IDs across the exchange. Only request and response are logged at
opening. Resolution appears only if the manager actually selects
revise; revalidate original subject and frozen lines before changing
the board. Keep/open use their previous wording. No re-fetch on
resume or option selection. Transcript retains line IDs, topic,
speaker and bank provenance without changing the public promo ledger.

The wording for effort and impact is deliberately conversational
rather than a reference to internal graph statistics. The partner
works WITH the call, not necessarily performing the move. No new
options, mood effects, signed mechanical contract or match execution changes.
The existing signed sheet speakers excerpt intentionally reflects the
new dialogue; assert it matches each transcript and compare all other
sheet fields exactly. The first CI failure confirmed only speakers differed.

Paired 80-room tests include offline snapshots, actual banks,
reloads, all choices, unchanged mood/contract and stale loading
tokens. MP6C must improve measured differentiation and topic variety;
MP6D adds multi-turn discussion rather than merely extra lines.
