# MP13 — real career audit

Run `node tests/planning-career-audit.test.cjs` for two 32-week seeded careers. For a wider sample run `node tests/planning-career-audit.cjs 3,10,24,41 48 > mp13-report.json`.

The existing world soak uses synthetic match outcomes. This new opt-in callback follows the actual booked card, signed structure, authored promo or signing, vow reconciliation, live psychology and actual graph execution. The normal career settlement wrappers process real results. All four structures and five approaches rotate; no forced moves, opening windows or artificial professional memory. The existing world decision/booking policy and starting grant remain unchanged. The real-bout sample omits synthetic mouthpiece/corner extras rather than claim they were actually simulated. Fixed choice policy is not player preference. The paired live-psychology-off replay is not settled in the career; it is a local same-seed sensitivity comparison, not a matched whole-career counterfactual.

Report covers per-structure and approach results, consent, outcomes, stars, crowd, calls, witnessed objectives, sequences, prior professional experience, academy involvement, stage resumes, and matched live psychology differences. Hard checks cover legal choices, immutable signed layout and contracted finish, witnessed receipts, bounded values, career invariants and duplicate settlement. Low delivery, high injury or unbalanced ratings are descriptive findings, not thresholds calibrated to desired outcomes. Review actual output before any tuning; no production engine changes in this PR.

## First measured baseline (PR #462)

199 matches, two 32-week careers, 1.677 mean stars, 34.729 crowd, 199 booked outcomes, 535/796 witnessed objectives and 160/728 witnessed named calls. 50 live-psychology comparisons: +0.015 mean stars, +0.36 crowd, -0.02 ignored calls, no changed outcomes. No sequence was signed because the decision policy skipped the optional hearing and acceptance. The original dialogue count also incorrectly used the display name rather than speaker side. These two results were coverage defects, not evidence that the production systems were unused by real players.

The revised policy rotates sequence-first, counter-first and single-call decisions, reports offers/hearings/selections/signings separately, measures actual dialogue, and adds same-booking traditional planning comparisons (same seed, approach, participants and promo result; separately negotiated sheet). The latter isolates neither the structure nor the planning model individually; it is a local policy comparison. No production tuning yet.

## MP13C revised calibration

The abandoned preparation-weight experiment (#464) did not improve completions (48 vs 47 in 137 paired trials; 40 no-opening misses in both). Diagnostic observation counts: 1557 runway/safety, 1381 prerequisite pending, 1201 wrong control, 911 wrong position, 658 exact entry, 636 first move offered, 22 illegal first move, 35 prep offers. These are repeated observations across replays, not unique bouts. No reason to merge that experiment.

Replacement: planning policy v3 adds an independent shared-kernel feasibility prior for common entry positions, usable window (including expected preceding objective timing), retained grip prerequisites and actual graph move duration classes. Rank bounded candidates before shortlisting and again at final selection; only select authored valid fragments. Existing psychological stances, risk checks and signed final action stay authoritative. Timing v1 estimates ten seconds for immediate attacks and twenty for committed grapples/aerial attacks, preserving the same minimum 45-second finish runway, 91% cutoff and hazard gates. Old in-flight matches retain original timing; old rooms retain their frozen offers. Alternate starts are considered by existing discovery before signing, not substituted after signing; runtime alternative-entry contracts remain deferred pending results.

Matched audit replays policy 2 and policy 3 on the same booking with the same decision policy, same seed, same supplied promo result and same workers. This measures the combined selection/timing change, not individual causal effects; track signed rates, absolute completions, both-signed completions, no openings, stars and injuries. No counterfactual changes career state. Do not merge if there is no measured benefit or unacceptable tradeoff.

## MP13D — signed adaptive openings

New room opt-in negotiates up to two fallback first moves which converge on the identical signed second-step state, preserve the performer, suffix and final call, and satisfy existing graph, medical, restriction, cost, grip and both-worker fuzzy feasibility checks. Alternatives appear in the manager-facing discussion before signing; sequence v2 stores only explicit entry state and first move. Existing v1 contracts remain unchanged. A fallback is only offered if the original is not available or the actual entry differs; a naturally landed signed fallback can count too. Receipts identify a genuine alternative landing as adapted (not exact), verify all subsequent graph events, and retain the existing one-adaptation maximum. No state assignment or invented landings. Compare policy 3 with/without the new opt-in on same-seed real bookings; separate signed fallback availability, adapted receipts, no-opening misses, stars, injuries and outcome changes. Benefit is unverified until CI logs are inspected.
