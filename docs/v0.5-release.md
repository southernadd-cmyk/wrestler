# The Office — v0.5.0 release guide

**Release date:** 20 November 2026  
**Code scope:** Cumulative, reviewed match-engine changes following v0.4.0; this release consolidates the existing gameplay implementation and introduces repeatable Graph Lab match-review fixtures.

> The matches are scripted. The people aren't.

## What changed since v0.4

v0.5 concentrates on **what happens between the bell and the finish**. Position-aware grappling, counter sequences and named attempts have grown into deeper technical chains. Standing exchanges, running attacks, neck work, top-rope actions, rest holds, pins and near-fall defences now have fuller authored relationships. Expanded training backgrounds guide eligible, reviewed move choices; the wrestler's presentation style and weekly career training remain separate.

This release does **not** claim to have implemented 325 new moves. The verified current match graph has **980 action nodes, 6,413 directed links and 25 arcs**. The live authored catalogue is 340 moves across 20 families; the later editorial audit documented mechanics for 325 identifiable techniques and classified 15 other catalogue events as match-performance beats rather than technical moves. Those 15 remain in the game.

## Mat and ringside highlights

- Position- and attempt-aware grappling, reversals and committed sequences.
- Mat holds, ground strikes, pin combinations and nearfalls, with follow-on defences.
- Expanded standing striking, running attacks, high-risk and neck-focused sequences.
- Distinct technical-school affinities and authored move-chain depth where live graph links exist.
- Better deterministic test coverage of phase timing, action legality and match diversity.
- A new Graph Lab Run-sheet picker with six review scenarios, backed by a 600-bout automated workflow.

## Player compatibility

This update does not add a new save format or require a fresh career. The Graph Lab remains a read-only tool outside ordinary career navigation. The mechanics metadata is not a replacement for the game engine: it must not silently change school multipliers or introduce impossible transitions.

## Further work

Cross-family reachability, false-safe moves, repetition of commentary and worked-match plausibility should be investigated from real bout tapes before adjusting any further graph weights. Winning a test suite does not, by itself, prove that a wrestling match tells a compelling story.
