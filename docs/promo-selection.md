# Phase 5B — contextual selection pilot

The live browser opts into authored dialogue for new scenes; existing in-progress scenes retain their original flags. The first production bank contains 73 individually written lines for Mara Vale, Brick Mercer, Nova Bell and Magnus, covering selected openings, replies and directed follow-ups on both sides of the exchange.

Selection matches speaker ID/role, exact decision, side, public conditions and, where applicable, an explicitly approved graph variant. Fresh qualified lines are ranked by condition specificity with a stable seeded tie-break. Used IDs and recent IDs are excluded; if none qualify, the existing graph wording is used rather than repeating an authored line or borrowing a different wrestler's. The recent snapshot uses the rivalry's last promo and the most recent 12 recorded match history entries, capped at 128 IDs. IDs persist through the existing history/rivalry result contract; no additional save migration is needed. This is bounded line-level avoidance, not permanent semantic memory or a guarantee against repetition in the fallback bank.

The approved variant list is intentionally narrow: competitive proof against known wrestling styles, select crowd appeals, main-event swagger, composure and the answer to an opponent's named strength. Recorded cases, evidence, exact counter plans, imagery and all closing promises retain the graph's wording. Existing variant effects and choice IDs remain authoritative. Pilot lines are disabled for mouthpiece scenes until appropriate third-person content is authored. The original graph's promise/tactic and numerical outcomes are preserved. The player and opponent can both receive authored lines, and actual displayed dialogue plus selected IDs are recorded.

The audit counts authored utterances and unique IDs reached, rather than claiming the pilot represents all 200 characters. Tests cover deterministic ranking, condition and variant guards, recent/used exclusion, 360 paired simulated scenes, outcome parity, protected slots and exact serialized resume. CI has not yet verified these tests. The next writing batches should expand both coverage and the reviewed semantic variant map, including closing statements only when they preserve the precise match-verifiable commitment. Review sample transcripts, not just line counts.
