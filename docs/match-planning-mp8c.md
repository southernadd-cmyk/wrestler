# MP8C — witnessed delivery in pair psychology

The live director issues terminal receipts from the signed sequence,
actual graph tape, exact performers, contiguous states and authored
edges. No attempt counts as a landing. Substitutes must preserve the
signed final move. Incomplete chains retain their best verified
prefix, including zero landings when no opening was found. An
unverifiable or aged-off graph record generates no receipt.

The existing pair rivalry ledger stores up to four compact receipts
per meeting, inside its existing ten-meeting cap and once-per-contract
settlement guard. Both workers read the same pair history at the next
planning capture; future/current-contract rows are excluded. The four
most recent receipt-bearing meetings contribute graded, recency-weighted
evidence to the shared fuzzy proposal model for conditional sequences.
Completed or adapted sequences increase willingness; a witnessed,
interrupted prefix can increase reservations and counterproposal
inclinations. Missing data, unopened sequences and protected exits
do not create negative evidence. No automatic bond, trust, morale,
rating or finish changes; no accusation of deliberate disobedience.

The post-match screen distinguishes agreed chains from witnessed
landings and completion/adaptation/missed status. Existing saves,
non-sequence plans and single-move proposals retain prior behaviour.

Verification: actual live bouts, exact receipt checks, once-per-contract
career settlement, JSON persistence, next-meeting fuzzy evidence,
no cross-pair/future leakage and targeted authored-bridge substitution.
