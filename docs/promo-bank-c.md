# Phase 5C — first roster dialogue banks (initial tranche)

This PR adds 640 independently written lines, 32 per character, for Mara, Rex, Lyra, Brick, Juno, Sol, Dee, Kit, Dax, Val, Nico, Cal, Imani, Otis, Kira, Ezra, Red, Roxy, Silas and Night Shift. The 73 pilot lines remain, giving 713 authored lines across 22 unique wrestlers (Mara and Brick overlap the pilot; Nova and Magnus are not in this tranche). Bank files are loaded before the duel and combined by stable character ID. Shared slot metadata is not a dialogue generation template.

Slots cover competitive openings, crowd appeals, swagger, opponent replies, rebuttals, restraint, direct challenges, directed follow-up and five closing variants. Only exact, explicitly reviewed graph variants are rephrased; evidence, case commitments, particular match plans and unapproved closing variants remain protected. The approved win/clean closing statements explicitly preserve the relevant graph promise, and uncertain endings avoid inventing new promises. No changes to the booked finish or numerical effects. No new dependencies, workflows or save migration.

The agreed 84-lines-per-character target is not yet met: each first-bank character needs another 52 lines before counting earlier pilot content. This tranche does not cover all eight editorial categories equally (particularly vulnerability), and authoring more variants for recurring career events needs stricter factual state guards. It is not an editorial quality sign-off or full dialogue coverage. The next tranche should broaden those situations, cover age/pressure-specific lines and increase alternative phrasings without copying the same sentence structure across characters. Avoid repeating the same argument in nominally different lines.

Regression covers 640 structurally distinct entries, valid owner and slot eligibility, protected fallbacks, 800 paired live scenes, player and opponent reach, three kinds of closing promise and numerical outcome parity. CI is pending; not all structurally valid slots are guaranteed reachable for a particular wrestler at current stats. Full anonymous transcript review remains necessary.
