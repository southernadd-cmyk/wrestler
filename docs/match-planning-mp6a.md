# MP6A — private dialogue contract

Reuse OfficePromoIdentity.wrestler and bankId for authored workers,
and OfficeRookiePhraseFactory.runtime for future academy recruits.
Do not build separate character banks. A shared delivery adapter
maps existing delivery descriptions to seven reusable phrase families.
Identity capture accepts already-loaded banks, validates through the
existing decode/catalogue API, and retains only exact reviewed first
sentences from unconditional acknowledgement/respect rows. No whole
on-air promo line, public result, fabricated history or generic claim
is imported. Source IDs and fingerprints are retained, alongside
existing semantic classification when available. No safe fragment
means identity-family composition, not borrowing a different worker.

A private subject is derived from an actual legal alternative, the
current board and frozen MP5E response. Topics use factual graph
comparisons, not invented injury, crowd reaction or personal motives.
Separate request, partner response and resolution composition.
Resolution text is intended ONLY after manager chooses revise; MP6B
must wire it at that boundary. Receptive responses can reuse approved
bank excerpts; objections cannot. All content is deterministic and
supports a used-ID list. No change to promo behavior or gameplay in
this foundation PR; browser loading, frozen dialogue and actual
room integration are MP6B. Later MP6C will audit repetition, topic
coverage and expand safely reusable source excerpts if justified.

Test scans actual roster banks, future runtime rookie path, unrelated
bank rejection, unsafe line rejection, all 80 huddle scenarios and
pure deterministic composition. Coverage numbers are diagnostic;
there is deliberately no claim all banks contain safe private speech.
