# MP7B — private negotiation of conditional setups

New structured rooms opt in to an optional third kind of discussion:
talk through a connected setup for a legal alternative. If the manager
hears a counteroffer first, the sequence targets that second card where
possible; otherwise the initial alternative. One ranked proposal per
discussion, with a preference for a near-equivalent control-changing
chain. No new per-character banks. The shared composer provides reviewed
leads, while the bodies describe the actual sequence, stance and caveats.

The road agent identifies each action's performer, starting state,
difficulty and live guards. Revalidate exact evidence, both fuzzy
scores, reactions and composed lines on reload and at selection.
The discussion itself is free of mood/board changes. After hearing it,
choose the named call with its provisional setup or choose an existing
single-move option. No more counteroffer after the setup exchange,
keeping the scene bounded. Old rooms have no new choices.

If the provisional setup is selected, apply the sequence-specific
fuzzy reactions exactly once and retain normal board credit. The
preview includes both. The original finish and route stay fixed.
Store the tentative setup in the room. Review and choice text make
clear that this version signs only the final named call, not the full
chain. MP7C will implement signed conditional sequence commitments;
MP8 will implement live execution and outcomes. No phantom landed
moves, guaranteed execution or new match simulation rules in MP7B.

The regression audit covers 80 rooms, online/offline banks, counter-first
and direct routes, deterministic reload, bans, tampering, old choices,
explicit mood effects and final sheet parity across selected branches.
