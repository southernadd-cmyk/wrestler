# MP5D — conditional sequence evidence

The existing board still describes dramatic landmarks, not contiguous
sequences. Never infer adjacency from four named objectives. The new
optional sequence argument to evaluateProposal is an explicit
2–6-action fragment ending at a validated existing call. Its proposed
entry state supplies control, position and down. Room.sequenceEvidence
checks actual positive graph edges, positional continuity, mat control,
performer ownership, timing ceiling, room bans, size and agility.
Ordinary reversals switch control; generated counter/block alternatives
cannot follow an already-landed parent. Pins/finish threats are outside
this slice. No execution or sheet changes.

The exact graph costOf function is exposed read-only, so default costs
are not invented. Static evidence preserves entry/exit state, performer,
cost, risk and unresolved live conditions (grip, location, stamina,
timing, hazard). Conditional fragments are NOT guaranteed executable:
the engine must still verify its detailed physical state and actual
timing. No chance of success or injury is inferred.

Difficulty is a provisional bounded design index: 8 per additional
action, 3 per positive authored cost point, 5 per position change,
6 per control change and 8 per step with grip/location prerequisites.
Clamp to 0–100. Track per-performer effort separately. Both parties
evaluate overall fragment complexity; do not equate effort with recipient
pain. Risk remains a separate proposal axis. Three acceptance rules,
nine reservations rules and nine counterproposal rules interact with
the existing difficulty curves, caution and flexibility.

Without an explicit sequence, sequenceDifficulty stays null and all
existing MP5A–C results stay unchanged. Invalid fragments yield no
assessment. A full ordered negotiation and actual execution belong to
MP7/MP8; MP5E can use single-call inference without inventing sequences.

Tests use real graph predecessors across 80 rooms, verify transitions,
ownership, replays, hard blocks, role-specific effort and absence of
sequence scores for ordinary calls. No added CI workflow or save fields.
