# MP4B — psychological initiative

New structured rooms created through the UI opt into version 1 of
initiative. Existing MP4A evidence-bearing saves without the marker
continue to use the original seeded non-lead-first selection; an
already-open huddle is never recalculated.

The room enumerates existing named objectives and same-owner legal,
compatible alternative cards. Both wrestlers can initiate discussion.
For each candidate the shared fuzzy profiles rank assertiveness,
caution against an actually safer/less taxing move, ambition and
protectiveness against improved crowd impact, flexibility against an
actual learned/signature move, protectiveness against actual finishing
route support, and mentorship against a simpler move with a developing
partner. These are bounded heuristic preference components, not
probabilities or yet a full proposal-evaluation model. The engine
continues to own eligibility and legality. A deterministic seeded
tie-break is used only after the score. No random stats or new traits.

The selected reason is the strongest applicable positive component,
excluding general initiative and the no-alternative component. It
drives a factual prompt using only candidate metadata. No claim that
a move will land or that the partner has already agreed. The existing
keep/revise/open choices and MP4A reaction policy remain. No changes to
the agreed result or finishing route, graph, safety, or promo system.

Test fixtures cover matched preference inputs, 80 huddles across four
structures, five approaches, both leads and both results, legacy
selection isolation, actual legal moves, same-owner alternatives,
signed sheets and exact JSON replay. Existing MP4A tests retain their
original scope. CI measures changed proposal count and reason coverage.

Limitations: current structure cards usually offer only one alternative
per owner. This phase ranks objectives and existing counterproposals,
not a new move-search system; initiative is not a general negotiation
policy. Character-specific speech and proposal evaluation follow later.
