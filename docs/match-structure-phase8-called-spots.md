# Match Structures — Phase 8: named-call execution and truthful assessment

## Diagnosis
Phase 7's controlled 960-bout audit recorded low named-call completion in Classic American (4.0%) and King's Road (3.1%), versus Chickenshit Heel (29.0%). These figures came from objective-ledger evidence, which stops recording when the broader objective resolves. A named move could subsequently land within its agreed window and remain invisible to that metric. The non-Heel Directors also weighted only existing action candidates; a signed move absent from those candidates had no chance of being selected. The backstage shortlist accepted some move families the Director would never recognise.

## Bounded repair
1. Structure-specific backstage suggestions now use the Director's objective compatibility filter. Existing signed sheets, legacy planning and metadata-only saves are unchanged.
2. In Classic American, King's Road and Dominant Ace, a signed named move can join the ordinary selection pool *during its current objective's window*, but only for its actual performer and compatible intent. Every original physical, timing, stamina, exact-parent counter, safety and wrestler-selection rule still applies. The Phase 7 Chickenshit Heel preferences remain intact.
3. The final named-call report scans performed graph actions independently from the dramatic-objective ledger. Exact move, signed performer and signed time window are all required. Completing an objective early does not hide a later named call. Objective achievements and star ratings are not artificially credited.
4. The existing Phase 7 paired Graph Lab audit independently proves each reported call against the physical tape and adds the matched metadata-only control's call rate, separating gameplay improvement from accounting correction.

## Review gate
Run the existing Simulation tests workflow (do not create another). Require the exact Phase 0 fingerprint, Phase 1–7 safeguards, matched 960 bouts crossing all four structures, two leads, five plans, four style pairings and three lengths, plus Chromium browser journeys. Inspect the active/control call difference, structure coherence, match quality, booked finishes, fallout and safety before deciding on merge. Never force a called move, booked result, or automatic rating.


## Focused botch attribution diagnostic
The match engine increments `M.botches` only for **scripted spectacle attempts** and the extraordinary balcony dive, not the ordinary, `isValid`-gated graph attacks that the Phase 8 called-spot Director can offer. Therefore, a rise in `M.botches` is a real match-quality concern, but does **not** establish that the called move itself became unsafe. The audit now reports, by structure, plan, style and duration: active/control botches; scripted spot attempts and failures; balcony botches; and the prevalence of risky named calls. Safe-layout assertions verify that any scripted attempt is restricted to the already guarded diving elbow and cannot include balcony botches. Check the actual data before altering the 4.2 preference weight. All analysis runs in the existing CI workflow, with no new test workflows.
