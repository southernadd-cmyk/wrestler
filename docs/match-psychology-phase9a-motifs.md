# Match Psychology Phase 9A — recurring grappling motifs

An opt-in, evidence-based pilot for actively structured matches. A genuine blocked or countered **committed named grapple** creates a single remembered motif, if it happens early enough. Later, the same performer may be guided towards a real fresh grip and offered the exact same move through the ordinary graph selection pool. Move legality, ownership, timing, fatigue, training, size, safety, counter outcomes and the contracted finish remain authoritative; a repeat is never guaranteed.

A motif is marked 'paid' only when the same wrestler subsequently lands the exact grapple in a new real attempt. Commentary acknowledges only verified failures and genuine payoffs; no fabricated attempts, forced counter, invented damage, rating multiplier or automatic crowd lift. Post-match `final.matchMotif` appears only when the first defended attempt can be located in the actual attempt ledger.

One motif maximum per match; Safe excludes risky or expensive choices, and metadata-only/legacy matches never activate motifs. Graph state is serialisable, and existing saves without motif state behave normally. Dedicated tests verify all four structures, physical legality, true counter and payoff, owner, grip entry, save restore, Safe and metadata-only isolation.
